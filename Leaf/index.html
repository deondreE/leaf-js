    Leaf rundown

    Leaf is a extension of the canvas html attribute, it takes advantage of the web component technology! Currently you can use leaf for static imports only.

    The usage of the web-component is all that is required no other setup in its current state, everything is controlled under the hood for basic file rendering. This is super useful if you just want to export a model from blender and render it say in a portfolio just install leaf and write this one web-component and your done.

    Usage

    <html>
  <body>
    <l-canvas src="initScene"></l-canvas>
  </body>
  <script lang="ts">
    import * from 'leaf';

    function initScene(): SceneFactory {

    }

    window.initScene = initScene()
  </script>
</html>

    <!-- Vanilla js example -->
<html>
  <body>
    <leaf src="object.stl" editors="true"></leaf>
  </body>
</html>

    A Note on Leaf Editors

    Leaf will eventually support

    • Material Editor.
    • Model Editor.
    • Particle Editor.
    • Node-Based Scripting.

    Supported File Formats

    Currently we support for static file imports:

    File Format Import Supported Animation
    .fbx yes no
    .stl yes no
    .obj yes no
    .mtl yes no
    .aesprite yes yes
    .jpeg no no
    .png no no
    .gif no no
    .psd no no
